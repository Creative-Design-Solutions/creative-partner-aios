# Integrations Guide — Creative Partner AIOS

Your AIOS grows more capable as you connect it to the tools you already use. None of these are required on Day 1 — start simple and add as you need them.

---

## Tiers of Setup

### Tier 1 — Local (Start Here)
Everything runs on your computer. No accounts, no hosting, no backend. Perfect for getting started and building confidence.

**What you get:**
- Full Claude Code experience in VS Code
- All skills available
- Invoice generator and apps running in your browser
- Session logs, decisions, and memory all saved locally

**What you need:**
- VS Code + Claude Code extension
- An Anthropic API key (claude.ai/code)

**Setup time:** 30–60 minutes

---

### Tier 2 — GitHub Connected
Your work is versioned, backed up, and shareable. Each project lives in its own repo. You can collaborate, roll back, and access your work from any machine.

**What you get:** Everything in Tier 1, plus:
- Version history for every change
- GitHub Pages for hosting apps and tools (free)
- Ability to share tools with clients via a URL
- Foundation for hosting client-specific generators

**What you need:**
- GitHub account (free)
- Git installed locally

**Setup time:** 1–2 hours

---

### Tier 3 — Full Backend
Connect to live data, send emails, process payments, and build apps that do real things in the world. This is where the AIOS becomes a true business operating system.

**What you need depends on what you're building** — see categories below.

## What to Connect First

Not sure where to start? Here's the recommended order based on impact:

1. **GitHub** — backs everything up, unlocks hosting
2. **Gmail or Outlook** — your AIOS can help with communication immediately
3. **Google Drive or Notion** — gives your AIOS access to your existing documents
4. **Your billing tool** — Xero, Stripe, or manual invoicing via the invoice generator
5. **A task manager** — ClickUp, Notion, or Linear so projects have a home

Everything else grows from there.
