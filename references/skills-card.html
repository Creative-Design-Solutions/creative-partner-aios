Skills Reference

Every skill — what it does, when to use it

Universal — every client
/welcome
Day 1 setup wizard. Asks 7 questions, builds your AIOS identity, generates your personal skills guide, and scaffolds all your context files.
Best when: you've just cloned the kit and are getting started
/morning-coffee
Session start ritual. Reads recent changes, loads memory, and gives you a calm oriented brief before you touch anything.
Best when: opening any work session
/snag
Searches the web before touching any code. Finds known issues, API changes, and breaking changes in seconds.
Best when: something breaks unexpectedly or an API stops working
/audit
Scores your AIOS against the Four Cs — Connection, Consistency, Capability, Creativity. Top 3 fixes ranked by leverage.
Best when: Day 7, then weekly — watch the score climb
/level-up
Weekly growth ritual. Finds one automation worth building, scopes it, and ships it. One run = one shipped artifact.
Best when: every Friday — this is how the system compounds
/skill-builder
Teaches your AIOS a new behavior. When you find yourself giving the same instructions session after session — build a skill.
Best when: you've given the same instructions 3+ times
/file-organizer
Intelligently organizes files and folders — finds duplicates, suggests better structures, cleans up the digital workspace.
Best when: folders feel chaotic or hard to navigate
/meeting-insights-analyzer
Analyzes meeting transcripts for communication patterns — filler words, conflict avoidance, listening gaps, leadership moments.
Best when: you have a transcript and want honest feedback on how you showed up
/smooth-operator
Logs a UX improvement — captures what changed, why it feels better, and the principle behind it for future reference.
Best when: after fixing something clunky — save the lesson
Creative — designers, writers, visual thinkers
/design-master
Full creative design mode — websites, UI, brand, emails, logos, identity, SVG assets, design tokens, and AI image generation. Stays active all session.
Best when: starting any visual or brand work session
/brainstorming
Explores intent, requirements, and design before any implementation. Gets alignment on what you're actually making before a single line is written.
Best when: starting something new and the direction isn't fully clear
/canvas-design
Creates beautiful visual art — posters, prints, illustrations — as PNG or PDF. Original designs, never copying existing artists.
Best when: you need a visual artifact, not a website or UI
/content-research-writer
Research-backed content writing — citations, hooks, outlines, real-time feedback on each section. Collaborative writing partner.
Best when: writing anything that needs research behind it
/theme-factory
Applies a visual theme to any artifact — slides, docs, landing pages. 10 pre-set themes or generate a custom one on the fly.
Best when: a deliverable needs a consistent visual identity
/image-enhancer
Improves image quality — resolution, sharpness, clarity. Good for screenshots, photos for presentations, or images for social media.
Best when: an image is too low-quality to use as-is
/brand-guidelines
Applies brand colors and typography consistently to any artifact. Use when visual formatting and design standards need to be enforced.
Best when: building client-facing materials that need to stay on-brand
Business — office, admin, client work
/invoice-organizer
Organizes invoices and receipts for tax prep — reads files, extracts key info, renames consistently, sorts into folders.
Best when: tax season or when billing files are scattered
/internal-comms
Writes internal communications — status reports, leadership updates, newsletters, FAQs, incident reports, project updates.
Best when: you need to communicate something to a team or organization
/changelog-generator
Creates user-facing changelogs from git commits — turns technical commit history into clear, customer-friendly release notes.
Best when: shipping an update and clients need to know what changed
/document-skills
Work with Word docs, PDFs, PowerPoint, and Excel — create, edit, fill forms, extract data, and produce professional office documents.
Best when: a deliverable needs to be in an Office format
Builder — developers, system builders
/writing-plans
Turns a spec or requirement into a detailed multi-step implementation plan before touching code.
Best when: the build has multiple moving parts or spans more than one session
/executing-plans
Executes a written plan with review checkpoints in a clean session. Pairs directly with /writing-plans.
Best when: you have a finished plan and are ready to build
/systematic-debugging
Structured root-cause tracing before any fix is proposed. Fixes that stick, not patches that move the problem.
Best when: something is broken and you don't know why
/verification-before-completion
Requires running verification commands before claiming work is done. Evidence before assertions — always.
Best when: you think something is fixed — prove it before moving on
/webapp-testing
Tests local web apps using Playwright — verifies frontend functionality, captures screenshots, views browser logs.
Best when: you need to verify UI behavior before shipping
/artifacts-builder
Builds complex multi-component HTML artifacts with React, Tailwind, and shadcn/ui — state management, routing, full component systems.
Best when: a deliverable needs interactive components, not just static HTML
/mcp-builder
Guides building MCP servers that connect Claude to external APIs and services — Python (FastMCP) or Node/TypeScript.
Best when: wiring Claude into a new tool or service
Growth — superpowers, frameworks
/superpowers
Activates the full skill system at the start of a session. Ensures Claude uses the right skill before responding to anything.
Best when: opening a complex or multi-step project session
/dispatching-parallel-agents
Runs independent tasks simultaneously across multiple agents. Big time saver on complex builds with parallel workstreams.
Best when: two or more tasks don't depend on each other
/skill-creator
Guides creating new skills following best practices — scaffolds, validates, and packages skills for reuse.
Best when: building a skill from scratch and want it done right
/writing-skills
Creates and edits skills — applies Anthropic best practices, tests before deployment, ensures quality.
Best when: refining an existing skill or writing a new one carefully
GSD Core
Spec-driven development system that prevents context rot on long projects. Install once per project: npx @opengsd/gsd-core@latest — then use /gsd-new-project, /gsd-next, /gsd-ship.
Best when: day one of a complex project — seatbelt, not airbag
